# 🕺 Perfect Challenge (퍼펙트 챌린지)

> **스마트폰 카메라만으로 즐기는 인터랙티브 댄스 챌린지 플랫폼**  
> **Developed by Team Demon of Street | 지도교수: 조겨리 교수님**

---

## 🎯 프로젝트 개요

**Perfect Challenge**는 인스타그램 릴스, 틱톡 등에서 유행하는 **숏폼 댄스 챌린지**를 기반으로,  
사용자가 실시간으로 춤을 분석하고 평가받을 수 있는 **모션 캡처 기반 댄스 플랫폼**입니다.

스마트폰 **전면 카메라(CameraX)** 와 **MediaPipe**를 활용해 사용자의 동작을 인식하고,  
기준 영상과 비교하여 점수를 부여합니다.  
**별도의 장비 없이, 언제 어디서나 춤 실력을 객관적으로 확인**할 수 있는 것이 핵심 목표입니다.

- **타겟 유저:** 10대 ~ 20대 초반 MZ세대 (특히 SNS 활용도가 높은 여성 이용자층)
- **플랫폼:** Android (Kotlin 기반)
- **핵심 키워드:** #댄스챌린지 #실시간채점 #MediaPipe #Gamification #AI평가

---

## 💡 프로젝트 배경 및 필요성

현대의 MZ세대는 단순히 콘텐츠를 소비하는 것을 넘어,  
**직접 참여하고, 공유하며, 성장하는 참여형 문화**를 추구합니다.

그러나 현재의 SNS 댄스 챌린지는 대부분 **‘감상’과 ‘참여’**에 머물러 있습니다.  
사용자는 “내가 얼마나 잘 추고 있는지?”를 알기 어렵습니다.

### ✅ 우리 프로젝트의 차별점
| 기존 플랫폼 | Perfect Challenge |
|--------------|-------------------|
| 감상 중심 (틱톡, 릴스 등) | 실시간 분석 및 점수 피드백 |
| 단순 유사도 기반 채점 (Just Dance) | 자세 + 박자 + 체형 보정 기반 AI 평가 |
| 외부 장비 필요 | 스마트폰 카메라만으로 가능 |
| 오락 목적 중심 | 실력 향상 + 몰입감 + SNS 확장성 |

## ⚙️ 주요 기능

### 🏋️ 1. 연습 모드
- 실시간 모션 캡처 분석 (MediaPipe Pose)
- 카메라 프리뷰 상단에 점수 표시
- 슬로우모션 및 구간 반복 연습 가능
- 피드백: 동작 정확도, 박자 일치도, 표현력 등

### 🏆 2. 챌린지 모드
- 제한된 생명(5개)을 소모하며 도전
- 점수에 따라 생명 및 뱃지 보상
- 만점 시 프로필 꾸미기 및 특별 뱃지 부여
- 결과 페이지에서 항목별 점수 확인 가능

### 📊 3. 랭킹 시스템
- 점수, 좋아요, 조회수 기준 정렬 가능
- 다른 이용자와 경쟁 및 랭킹 공유
- 개인 마이페이지에서 자신의 기록 확인 가능

### 🚀 4. SNS 공유 기능
- 인스타그램, 유튜브, 틱톡 등 외부 플랫폼 공유 기능
- 챌린지 영상 저장/삭제 기능 지원 (Firebase Storage)

|--------|------|

| **Firebase Auth** | 회원가입 / 로그인 / 사용자 인증 |
| **Firebase Storage / Firestore** | 영상 및 좌표 데이터, 챌린지 메타데이터 저장 |
| **Android Studio (Kotlin)** | 앱 UI, CameraX 연동 및 Mediapipe 호출 구현 |

## 🧮 채점 알고리즘 개요

1. **MediaPipe**로 관절 좌표 추출  
   → 33개 관절의 (x, y, z, visibility)

2. **좌표 정규화 및 벡터 변환**  
   → 골반 중심으로 좌표 정렬, 어깨 너비 기준으로 크기 보정  
   → 좌우 반전 비교 후 더 유사한 쪽 선택

3. **자세 유사도 계산 (Cosine Similarity)**  
   → 각 프레임별 벡터 방향 유사도 측정  
   → 1.0 = 완전 일치 / 0.0 = 불일치

4. **박자 유사도 계산 (DTW)**  
   → CameraX timestamp 활용  
   → 원본과 사용자 동작의 시간축 일치도 측정

5. **점수 산출**
   → 최종점수 = (정확도 × 0.6) + (박자 × 0.4)

6. **노이즈 및 체형 보정**
- 지수이동평균(EWMA)으로 노이즈 완화
- 프레임 사이 속도 기반으로 리듬 반영
- 팔 길이, 어깨 비율 등 체형별 스케일 조정
